Task B1 – Air Quality Data Cleaning Pipeline

Aim

To develop a Python-based data cleaning pipeline for processing air quality data and storing the cleaned information in an SQLite database.

Problem Statement

Raw air quality data may contain missing values, duplicate records, invalid values and inconsistent temperature units. These errors affect data analysis. This program cleans and processes the data to improve its quality.

Tools Used

- Python
- SQLite3
- Matplotlib
- CSV Module

Concepts Used

- Data cleaning
- Missing value handling
- Duplicate removal
- Data validation
- Fahrenheit to Celsius conversion
- Min-Max Normalization
- SQLite database operations
- Data visualization

Program File

"clean_pipeline.py"

Steps to Execute

1. Open the Python environment.
2. Install Matplotlib using "pip install matplotlib".
3. Run "clean_pipeline.py".
4. Check the cleaned records and SQL averages.
5. View the generated station comparison chart.

Expected Output

- Cleaned air quality records.
- Normalized PM2.5 values.
- Average PM2.5 values for each station.
- Station comparison chart.

Conclusion

The program successfully demonstrates air quality data cleaning, validation, normalization and database storage. It helps improve data accuracy and supports better analysis of air quality information.
